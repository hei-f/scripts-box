# Layout 布局组件

应用的主布局结构，包含侧边栏和顶部导航。

## 组件

| 文件 | 说明 |
|------|------|
| `MainLayout.tsx` | 主布局组件，包含侧边菜单和内容区域 |
| `index.ts` | 模块导出 |

## 使用

```tsx
import { MainLayout } from '@/components/Layout';

// 在路由配置中使用
<Route element={<MainLayout />}>
  <Route index element={<HomePage />} />
</Route>
```

## 结构

```
┌─────────────────────────────────────┐
│           顶部导航栏                 │
├──────────┬──────────────────────────┤
│          │                          │
│  侧边栏   │       内容区域            │
│  (菜单)   │     (<Outlet />)         │
│          │                          │
└──────────┴──────────────────────────┘
```
